# RibiClasses

These are copies of the components of
[RibiClasses](https://github.com/richelbilderbeek/RibiClasses)
that this game uses,
so that the game does not depend on that repository anymore.

The copies are from RibiClasses commit `2662560`.
Each folder has its own license.

Components:

- `CppAbout`
- `CppCanvas`
- `CppFileIo`
- `CppHelp`
- `CppMenuDialog`
- `CppTextCanvas`
