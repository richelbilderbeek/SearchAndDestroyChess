# Play

Play Search And Destroy Chess in your browser!

This is a two-player game on one computer:
take turns and do not look at the screen
during the turn of your opponent.

- Click on the board or press `Enter` to start your turn
- See [controls](controls.md) for the keyboard controls

This version is built from the same C++ code as the desktop version,
compiled to WebAssembly using
[Emscripten](https://emscripten.org/).
